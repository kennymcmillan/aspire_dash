3. Icon language

One rule: the icon says what kind of thing it is, the label says which one. Weapon = custom blade glyph (Font Awesome has no foil, epee or sabre), category = rising bars for the age ladder, level = tier icon in a tinted pill, source = coloured text tag, gender = mars, venus.
